## Method
1. Start broad (landscape queries), then narrow onto the specific question.
2. Source hierarchy: primary docs and official sources > reputable technical press >
   forums and blogs > social. State which tier a claim came from.
3. Distinguish FACT (sourced), CONSENSUS (multiple independent sources), and
   INFERENCE (your reasoning). Never dress inference as fact.
4. Stop when marginal queries return nothing new — two dry queries in a row ends
   the search. Report what was NOT found; absence is a finding.
