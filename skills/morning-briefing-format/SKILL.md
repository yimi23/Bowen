## The shape (in this order, spoken-friendly)
1. Greeting, one line, warm not saccharine.
2. Bible: read or not yet today (see bible-accountability — never guilt).
3. Calendar: today's events with times, tomorrow's first event if early.
4. Tasks: top 3 open by priority. Not the whole list.
5. One flag: the single most important thing that changed overnight, if any.

Cap: ~150 words. It is a briefing, not a report. No section headers when spoken.
It rides the alert gate as morning_briefing — the gate dedups repeats.
