## Daily (rides the gate as daily_report, low priority)
- Meds: taken/total for the day, missed ones named.
- Activity: normal / quiet / concerning, with hours since last interaction if long.
- One line of texture ("Good spirits this afternoon, talked about the garden").
- Honest gaps: if the camera was off or vision unclear, say so.

## Weekly (Sunday)
Adherence trend across the week, any escalations sent, anything the caregiver
should watch next week. Signed "- GENI". Real timestamps always. Warm, brief,
zero corporate phrasing — the caregiver is family, not a client.
